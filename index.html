🚄 Rail PK

Overlay Android affichant le point kilométrique (PK) ferroviaire en temps réel sur toutes les lignes SNCF

📥 Télécharger l'APK …

🔧 Comment ça marche

Rail PK utilise le GPS de votre appareil et le référentiel officiel des points kilométriques SNCF pour afficher le PK en superposition par-dessus n'importe quelle application — PDF d'aide à la conduite, navigation, etc.

📱 Installation

  1. Télécharger l'APK
  2. Autoriser les sources inconnues dans Paramètres → Sécurité
  3. Installer l'APK
  4. Au premier lancement, accepter les permissions (affichage par-dessus, localisation, batterie)

📖 Utilisation

  1. Ouvrir un PDF d'aide à la conduite (Adobe Reader) — optionnel
  2. Lancer Rail PK
  3. Appuyer sur Démarrer — la fenêtre overlay apparaît
  4. Déplacer la fenêtre par glisser-déposer, pincer pour redimensionner

La fenêtre affiche le PK en grand, le code ligne, la vitesse moyenne et la distance parcourue.

⚠️ Avertissement

Aide visuelle, pas un instrument réglementaire.
